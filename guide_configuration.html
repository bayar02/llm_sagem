📖 Notions essentielles

Les mots-clés à comprendre

Avant de configurer votre produit, voici les 6 notions fondamentales expliquées simplement. Cliquez sur chacune pour l'ouvrir.

📄 ICP — Inspection & Control Plan

▼

L'ICP est un document officiel PDF qui liste toutes les limites de tests que doit respecter votre produit en usine.

Pensez-y comme une fiche technique de recette : il indique pour chaque test quelles valeurs sont acceptables (minimum et maximum).

📌

Exemple : L'ICP peut indiquer que la puissance Wi-Fi doit être comprise entre 14 dBm et 20 dBm. Si un appareil mesure 12 dBm, il est hors limite → FAIL.

📑 MTP — Manufacturing Test Protocol

▼

Le MTP est le rapport des tests réellement effectués sur un appareil en production. Il contient les valeurs mesurées.

Si l'ICP est la recette, le MTP est le résultat du plat. L'outil compare les deux pour voir si le produit est conforme.

✅

Le MTP est analysé par l'IA de l'outil, qui extrait automatiquement les valeurs mesurées depuis le PDF.

🧩 Module — Type de test

▼

Un module représente une catégorie de tests. Votre produit peut avoir plusieurs modules selon ses fonctionnalités.

📺

Front-End (FE)

Tests DVB-C, DVB-S, DVB-T. Présent seulement sur les produits avec tuner TV (décodeurs cable/satellite).

📶

RF Wi-Fi

Tests Wi-Fi 2.4 GHz et 5 GHz (puissance, EVM, erreur de fréquence).

🔵

Bluetooth

Tests Bluetooth (puissance TX/RX, dérive de fréquence).

⚡

Board Level (ICT)

Tests électroniques : tensions d'alimentation, démarrage, mémoire.

🖥️

System Functional

Tests fonctionnels : HDMI, Ethernet, USB, LED, boutons, température.

💾

FW Upgrade / Final

Tests de mise à jour firmware, vérification MD5, personnalisation SFIS.

🔍 Parser — Le lecteur de logs

▼

Un parser est un programme qui sait lire un type spécifique de fichier log. Il extrait automatiquement les résultats de tests.

Chaque module a son parser dédié, déjà configuré dans l'outil. Vous n'avez pas à comprendre son fonctionnement interne.

💡

Règle simple : L'outil vous suggère automatiquement le bon parser quand vous chargez un fichier log. Faites confiance à la suggestion affichée en vert !

📦 Extractor — Le lecteur de PDF ICP

▼

L'extractor lit le PDF ICP et en extrait les limites (min/max) pour chaque test. Il travaille au moment où vous chargez le PDF ICP dans l'étape 2.

⚠️

Important : Les modules BoardLevel, System et FW Upgrade n'ont pas besoin d'extractor — leurs limites viennent directement des logs (l'appareil écrit lui-même les limites dans le fichier). Laissez le champ sur "Aucun extractor".

✨ Bonne nouvelle

L'outil pré-remplit automatiquement le bon parser et extractor pour chaque module connu. Dans 90% des cas, vous n'avez rien à changer !

🤔 Quand dois-je changer quelque chose ?

📌 Si l'outil affiche "Aucun parser compatible"

▼

Cela signifie que le module sélectionné n'a pas de parser associé dans l'outil. Retournez dans l'onglet 🔍 Parsers et vérifiez que le parser existe et est bien marqué compatible avec ce module.

📌 Si vous voyez "Aucun extractor compatible"

▼

Pour les modules BoardLevel, System et FW Upgrade, c'est normal et attendu. Ces modules n'ont pas besoin d'extraire des limites depuis un PDF ICP — elles sont dans les logs. L'outil affiche simplement un message informatif, pas une erreur.

💡

Comment l'outil suggère le bon parser ?

Quand vous chargez un log, l'outil analyse automatiquement les premières lignes du fichier et affiche une suggestion avec un score de correspondance. Un score ≥ 70% en vert = bonne suggestion. Faites confiance à cette suggestion.

📄 Partie ICP — Essentiel

Comprendre le document ICP

Le document ICP est le cœur de la configuration. Il définit les limites de conformité de votre produit. Voici comment le reconnaître et l'utiliser.

📁 Comment reconnaître votre fichier ICP ?

Le fichier ICP est toujours un PDF dont le nom contient généralement "ICP" ou "PRODUCT" :

ICP_PRODUCT_VODAFONE_DIW253_v0.3.pdf ← votre ICP ICP_PRODUCT_DISH_DCIW377_v0.4.pdf ← ICP DISH ICP_PRODUCT_LOWI_DIW252_v0.2.pdf ← ICP LOWI
⚠️

Ne confondez pas le PDF ICP avec le PDF MTP ! Vérifiez le nom : ICP = spécifications, MTP = résultats mesurés.

📊 Que contient le PDF ICP ?

⚡

Tensions ICT (Part 6)

Tableau des tensions d'alimentation (ex. 12V, 3.3V, 1.8V) avec limites min/max pour chaque point de test (PT15xxx).

📺

Tests FE DVB (Part 8.1)

Pour décodeurs uniquement. Liste les fréquences et modulations DVB-C/S/T à tester avec limites BER, SNR, RSSI…

🖥️

Tests fonctionnels (Part 8)

HDMI, Ethernet ping, USB, LED, IR, boutons — avec valeurs attendues (souvent PASS/FAIL = 1 ou 0).

📶

Tests Wi-Fi / BT (Part 8.9+)

Limites de puissance TX (dBm), EVM (dB), tolérance fréquence (ppm), PER (%) pour chaque fréquence et modulation.

📌

Bon à savoir : Le JSON rf_limits

Pour certains produits (DISH, LOWI), un fichier *_rf_limits.json accompagne le PDF ICP. Ce fichier contient les limites RF en format structuré — l'outil l'utilise directement sans extraction PDF. Si ce fichier existe, utilisez-le en priorité pour les modules RF Wi-Fi et Bluetooth.

📤 Étape 2 dans l'application

Charger et extraire le PDF ICP

Dans l'application, passez à l'Étape 2 — Extraction ICP. Voici exactement quoi faire et à quoi s'attendre.

1

Vérifiez que le bon produit est sélectionné

En haut à gauche de l'interface (barre latérale), vérifiez que votre produit est affiché comme "Produit actif". Sinon, sélectionnez-le dans la liste.

2

Cliquez sur "📁 Charger le PDF ICP"

Une fenêtre s'ouvre — naviguez jusqu'à votre fichier ICP_PRODUCT_*.pdf et sélectionnez-le. L'outil lit immédiatement les premières pages et affiche une suggestion.

3

Lisez la suggestion automatique

Un encadré vert apparaît avec le meilleur extractor détecté. Exemple : "L'extractor Extractor FE ICP v2 correspond à 6/8 marqueurs". C'est une bonne correspondance — continuez.

4

Cliquez sur "🚀 Lancer l'extraction ICP"

L'outil analyse le PDF (10-30 secondes) et extrait les limites pour chaque module. Une barre de progression s'affiche.

5

Vérifiez les résultats

L'outil affiche un tableau récapitulatif des tests extraits. Vérifiez que le nombre de tests correspond à ce que vous attendez (consultez le PDF ICP si besoin).

🚫

Problème : "0 tests FE extraits" alors que j'ai des tests DVB

Vérifiez que le module FE est bien activé dans la configuration du produit et que l'extractor Extractor FE ICP v2 est sélectionné pour ce module. Si le module FE n'est pas coché, l'extraction ne se fait pas.

🚫

Problème : Erreur "PermissionError" sous Windows

Ce problème est corrigé dans la version actuelle. Si vous le rencontrez encore, fermez l'application et relancez-la. C'est un problème de fichier temporaire verrouillé.

💡

Conseil : Pour les produits RF Wi-Fi / Bluetooth avec JSON

Si votre produit dispose d'un fichier *_rf_limits.json, chargez-le à l'étape 3 (Validation Logs) plutôt que d'extraire les limites RF depuis le PDF. Le JSON est plus précis et plus complet.

📋 Étape 3 dans l'application

Charger et valider les logs d'équipement

C'est l'étape où l'outil compare les mesures réelles (dans les logs) aux spécifications de l'ICP. Vous pouvez charger plusieurs logs simultanément.

📁 Quels fichiers charger ?

Chargez tous les fichiers log de votre session de test. Pour un produit complet, vous en avez généralement 5 : BoardLevel, RF, System, FW_Upgrade, Final.

🎯 Comment ça marche — Assignation automatique

Quand vous chargez plusieurs logs, l'outil analyse chacun et suggère automatiquement :

Fichier logModuleParserMatch
📄 1+BoardLevel-...PASS.log ⚡ Board Level Parser BoardLevel v1 ✓ 67%
📄 1+RF-...PASS.log 📶 RF Wi-Fi Parser RF v15 ✓ 83%
📄 1+System-...PASS.log 🖥️ System Parser System v1 ✓ 57%
📄 1+FW_Upgrade-...PASS.log 💾 FW Upgrade Parser FW/Final v1 ✓ 43%

Si une assignation vous semble incorrecte, modifiez-la manuellement avec les listes déroulantes avant de lancer la validation.

⚠️ Problèmes & Solutions

Erreurs fréquentes et comment les résoudre

Voici les problèmes les plus courants rencontrés lors d'une première configuration, avec les solutions exactes.

🔴 "Aucun parser compatible" pour un module

▼

Cause : Le module est coché mais aucun parser dans le catalogue n'est configuré comme compatible avec lui.

Solution :

  1. Allez dans l'onglet 🔍 Parsers
  2. Cliquez sur ✏️ pour éditer le parser concerné
  3. Dans le champ "Modules compatibles", ajoutez l'ID de votre module
  4. Cliquez sur 💾 Enregistrer

🔴 Le bouton "Enregistrer" ne semble pas fonctionner

▼

Cause probable : Un champ obligatoire est vide (Nom du produit) ou une valeur invalide a été saisie.

Solution :

  • Vérifiez que le champ Nom * est rempli
  • Regardez s'il y a un message d'erreur rouge sous le formulaire
  • Si aucune erreur visible, essayez de rafraîchir la page (F5) et recommencez

🔴 Extraction ICP : "0 tests extraits"

▼

Causes possibles :

  • Le PDF est scanné (image uniquement, pas de texte) — l'outil ne peut pas lire les images
  • Le module correspondant n'est pas activé dans la configuration du produit
  • Le mauvais extractor est sélectionné pour ce module
  • Le PDF n'est pas un ICP mais un autre type de document

Solution : Vérifiez que votre PDF s'ouvre bien dans Adobe Reader et que le texte est sélectionnable (pas une image). Vérifiez la configuration du produit.

🔴 Validation logs : "Paramètre absent du log"

▼

Cause : L'ICP définit une limite pour un paramètre (ex. "Rate Offset") mais ce paramètre n'a pas été mesuré dans le log.

Ce n'est pas forcément une erreur grave ! Pour certains produits (ex. DVB-S), quelques paramètres peuvent être omis. Regardez la règle de test :

  • Règle Standard → avertissement (⚠️) — le rapport continue
  • Règle Strict → échec (❌) — le paramètre manquant bloque

Si vous voyez beaucoup de paramètres manquants, vérifiez que vous avez chargé le bon fichier log pour ce module.

🔴 Multiselect : valeur par défaut invalide

▼

Cause : Un parser ou extractor avait "Final" dans ses modules compatibles, mais "Final" n'est pas un module valide (c'est un type de log, pas un module).

Solution : Ce problème est corrigé dans la version actuelle. Si vous le rencontrez, allez dans l'onglet 🔍 Parsers, éditez le parser concerné, et retirez "Final" de la liste "Modules compatibles".

🔴 L'IA répond avec une erreur de connexion

▼

Cause : L'API interne est inaccessible (réseau, serveur arrêté, token expiré).

Solution : L'outil bascule automatiquement sur un mode de comparaison local (sans IA). Vous obtiendrez un rapport basique mais fonctionnel. Relancez l'analyse IA une fois la connexion rétablie.
